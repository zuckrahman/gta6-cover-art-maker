Vice Coast Cover Maker is an offline web app that turns any photo and a caption into a multi-panel poster cover in the style of GTA 6 posters: four layouts (four-panel grid, hero panel plus three, full bleed, tilted snapshots), crop, zoom and position controls per panel, several photos or one photo across every panel, bold Anton title lettering with a Pacifico script subtitle, Vice City sunset and neon colour grades with grain and vignette, and one-click PNG export in 1080 x 1080, 1080 x 1350 and 1920 x 1080. Photos are read on the user's own machine and never uploaded; the app runs entirely from static files with no network requests. All artwork and lettering are original, and the fonts (Anton and Pacifico) ship under the SIL Open Font License.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser, load a photo, pick a layout and grade, edit the caption, and export a PNG.
